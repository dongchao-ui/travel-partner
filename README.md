# 旅行伙计 TravelMate Agent

面向学生和年轻短途出行用户的一站式 AI 旅行规划 Agent。用户输入出发地、目的地、出行日期、天数、预算、兴趣偏好和硬性限制后，系统会整合天气、景点、交通、预算、攻略清洗和私有 RAG 笔记，生成分天、分模块、可落地的旅行方案。

项目重点解决传统旅行攻略制作成本高的问题：用户不需要在天气软件、地图平台、攻略社区和交通票务平台之间反复切换，也不需要手动筛选大量广告、重复和模糊信息。

## 核心功能

- 天气查询与出行判断：根据用户选择的出发日期查询对应周期天气，连续雨天或强降雨时优先给出改期建议。
- 景点规划：推荐具体 POI 和位置，避免只写“某某街区”这类模糊地点，并提供地图搜索入口。
- 多工具规划：整合天气、景点、交通、预算、攻略清洗和私有 RAG，生成完整旅行方案。
- 行程编排：按天、上午、下午、晚上生成行程，避免同一天或跨天重复安排同一景点。
- 攻略清洗：单独展示系统清洗规则和私有 RAG 命中内容，方便用户区分公开规则和个人攻略资料。
- 私有 RAG 攻略：支持上传 PDF/TXT/Markdown 收藏攻略，生成方案时检索用户私有笔记并参与规划。
- 方案自检：检查重复景点、雨天室外安排、预算超限、位置模糊、行程缺失等问题。
- 二次微调：支持降低预算、少走路、增加美食、雨天室内等快捷重排。
- Markdown 导出：完整攻略可导出为 Markdown，方便手机离线查看。

## 技术栈

- 后端：Python、FastAPI、Pydantic
- 工具调用：httpx、Open-Meteo、公开百科/攻略检索
- AI 能力：DeepSeek API 润色输出文案
- RAG：本地文件上传、文本切分、关键词召回，可升级为 Chroma + sentence-transformers
- 前端：HTML、CSS、JavaScript、Lucide Icons
- 部署：Docker / docker-compose

## 运行方式

```powershell
cd D:\codex-chat\travelmate-agent
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
copy .env.example .env
python run.py
```

打开：

```text
http://127.0.0.1:8000
```

## 环境变量

```env
DEEPSEEK_API_KEY=
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-chat
PORT=8000
```

不配置 DeepSeek 也可以完整运行；配置后会对导出的 Markdown 攻略进行语言润色。

- 优化注意事项排版：注意事项模块只保留预算、工具路由、方案自检、行李清单和风险边界，减少信息混杂。
- 增加缓存控制：静态资源加入版本号，首页返回 no-store 缓存头，避免浏览器使用旧样式或旧脚本。
