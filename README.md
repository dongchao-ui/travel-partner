# 旅行伙计 TravelMate Agent

面向学生和年轻短途出行人群的一站式 AI 旅行规划 Agent。用户只需要输入出发地、目的地、出行日期、预算、兴趣偏好和硬性限制，系统会自动整合天气、景点、交通、预算、攻略清洗和私有 RAG 笔记，生成可直接落地的分天旅行方案。

项目重点解决传统旅行攻略制作成本高的问题：用户不需要在天气软件、地图平台、攻略社区、交通票务平台之间反复切换，也不需要手动筛选大量广告和重复信息。

## 核心能力

- 天气查询与出行判断：根据用户选择的出发日期查询对应周期天气，雨天较重时直接建议改期。
- 景点规划：推荐具体景点和位置，避免“某某街区”这类模糊描述，并提供地图搜索入口。
- 行程编排：按天、按上午/下午/晚上生成行程，避免同一天和跨天重复安排同一景点。
- Agent 工具路由：根据用户输入判断本次是否需要交通、私有 RAG 等工具，并展示调用原因。
- 方案自检：检查重复景点、雨天室外安排、空行程、预算超限、位置不明确等问题。
- 二次微调：支持降低预算、少走路、增加美食、雨天优先室内等快捷重排。
- 私有 RAG 攻略：支持上传本地 PDF/TXT/Markdown 攻略，生成方案时检索用户私有笔记。
- Markdown 导出：完整攻略可导出为 Markdown，方便手机离线查看。

## 技术栈

- 后端：Python、FastAPI、Pydantic
- 工具调用：httpx、Open-Meteo、公开百科/攻略检索
- AI 能力：DeepSeek API 润色输出文案
- 本地知识库：轻量 RAG 文件上传、文本切分、关键词召回
- 前端：HTML、CSS、JavaScript、Lucide Icons
- 部署：Docker / docker-compose

## 运行方式

```powershell
cd D:\codex-chat\travelmate-agent
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
copy .env.example .env
python run.py
```

打开：

```text
http://127.0.0.1:8000
```

## 环境变量

```env
DEEPSEEK_API_KEY=
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-chat
PORT=8000
```

不配置 DeepSeek 也可以完整运行；配置后会对导出的 Markdown 攻略进行一次语言润色。

## 今日优化记录

- 修复出发日期 bug：天气查询现在严格按照用户选择的出发日期生成，例如 7 月 25 日出发就展示 7 月 25 日起的天气。
- 修复跨天重复景点 bug：全程维护景点使用记录，具体景点在一次旅行中只安排一次。
- 增加兜底时段：候选景点不足时，用轻量自由探索、附近餐饮/休息、夜间餐饮机动替代重复景点。
- 增加 Agent 工具路由：展示本次调用天气、景点、交通、预算、RAG 等工具的原因。
- 增加方案自检：自动发现重复景点、雨天室外点位、预算超限、位置需核实等问题。
- 增加景点地图入口：每个景点生成高德地图搜索链接，提升方案落地性。
- 增加二次微调接口和前端按钮：支持降低预算、少走路、增加美食、雨天室内等快速重排。
